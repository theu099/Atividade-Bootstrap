## O que é este projeto

Uma página com um card (um quadro com texto e botão) que muda de aparência ao clicar no botão.

- **Bootstrap** é uma biblioteca de estilos pronta, que deixa a página bonita sem precisar escrever todo o CSS do zero. Ela é carregada pela internet, por isso a página precisa de conexão para aparecer com o visual correto.
- **JavaScript** é a parte que faz a página reagir ao clique. Neste projeto, ele troca o título, o texto e as cores do card, e também muda a cor do botão.

## O que acontece ao clicar no botão

1. **Primeiro clique:** o card fica escuro, o texto muda para "Estado Atualizado!" e o botão fica verde.
2. **Segundo clique:** o card volta ao normal, o texto volta ao estado inicial e o botão volta a ser azul.

## Como abrir o projeto

1. Baixe o projeto clicando no botão verde **Code** e depois em **Download ZIP**.
2. Extraia o ZIP em uma pasta do computador.
3. Dê dois cliques em `mini-projeto-bootstrap.html`. A página vai abrir no navegador.

Obs.: o GitHub mostra o código do arquivo, e não a página. Para ver o projeto funcionando, abra o arquivo no navegador, como no passo 3.
